**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Fix

- **Uncharted 3 starts again.** 0.10.119 closed right at start ("Allocation failed: 8388608 bytes" in the log): its
  larger network memory pool did not fit the game's memory budget. The pool is now raised by a size that fits, which
  still prevents the crash in matches with three or four players.

## From 0.10.119

- **Guests see the enemies** in co-op arena, co-op adventure, hunter arena and shade (issue 58).
- **Every player's character look reaches everyone** (issue 57).
- **No crash at start** when the game is started again without restarting the launcher (issue 55).

Still being worked on: the freeze in custom games and matchmaking (issue 55), lag and teleporting players (issue 56),
and guests not throwing grenades (issue 59). Please attach your `boot.log` and any `hang-*.txt` from the
`analysis\big3-ps4_Shipping` folder to the issue.
