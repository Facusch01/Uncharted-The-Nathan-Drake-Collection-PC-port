**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 co-op (helper v7.242)

- **Fixed a crash on co-op guests** (seen in London): a leftover diagnostic read a removed enemy's memory.
- **Enemies on guests should no longer fly around or T-pose:** one part of an enemy's animation state was sent in
  a shorter form than guests read it, so guests could not decode the rest of it. Please tell us if you still see it.
- From 0.10.140: when one player's game freezes or crashes, the others no longer run out of network memory and close.
- From 0.10.139: network events no longer go missing (enemies, box progress, checkpoints, cutscenes).

All players should update. Still being worked on: a rare freeze in co-op, map lighting on Facility and a few other
maps, freezes in custom games, matchmaking and Fort co-op (issue 55), lag and teleporting players (issue 56). Please
attach your `boot.log` and any `hang-*.txt` / `u3mp-freeze.txt` from the `analysis\big3-ps4_Shipping` folder to the
issue.
