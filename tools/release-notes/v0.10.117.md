**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 3 co-op: fixes

- **Monastery (co-op adventure):** after you free Drake in the church he no longer stands in a T-pose, so he walks out
  with you and the level goes on. In co-op the game now uses the multiplayer animation settings, as the PS3 game does.
- **Syria (co-op adventure):** work on the freezes during the level. The sound mixing, the graphics command buffers and
  a job wait that could hang forever were changed; a full run now finishes in our tests, but this is not confirmed
  yet. If Syria still freezes for you, please send your `boot.log`.

## Uncharted 2 multiplayer

- **Joining a match:** the joining player now tells the host it is ready. Thanks to Tha14 (PR 30)!
- **Stability:** some test probes were removed and a few risky changes reverted. Thanks to Tha14 (PR 26)!
