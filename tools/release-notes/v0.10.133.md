**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 2 multiplayer

- **Much more of the multiplayer netcode now works** (by Tha_14): match events, grenades, HUD, medals, player
  animations over the network, scoreboard, unlocks and the session flow, for a far more reliable Uncharted 2
  multiplayer.
- **Party Up lists up to 250 RPCN friends** (was 64).

## Imports, Uncharted 3 and Uncharted 2

- **An update now redoes only what changed.** Before, an update reran most of the Uncharted 3 import steps even
  when one tool had only a message changed. Now a step runs again only when its own code, data or inputs changed (and
  the steps that rewrite the same files). The import log says why each step runs or is skipped.
- The first update with this change runs about 30 Uncharted 3 steps once more (a few minutes) to record the new
  fingerprints; after that, only real changes are redone.

Still being worked on: freezes in custom games, matchmaking and Fort co-op (issue 55), lag and teleporting players
(issue 56). Please attach your `boot.log` and any `hang-*.txt` / `u3mp-freeze.txt` from the
`analysis\big3-ps4_Shipping` folder to the issue.
