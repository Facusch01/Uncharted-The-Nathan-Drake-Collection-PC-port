**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 multiplayer: sharper maps and characters (recipe 1.29.0)

- **Map textures at full size.** Many map textures were drawn at 64x64 (for example 139 of Desert's 143 textures, and
  most of the co-op London, Syria and Airport levels): the converter took the small copy the PS4 game keeps while it
  streams the real one. They now come at full size from your PS4 game (or the PS3 one when PS4 has none): over 10,000
  textures in 124 map files.
- **More of each PS3 material kept:** shine (specular) layers, second normal maps and blend maps now find a matching
  PS4 material, so surfaces look closer to the PS3 maps.
- **Characters:** parts that had a flat placeholder texture now use their own PS4 map (shine and tint masks), for
  example the MP Talbot, the MP kit heads, arms, legs and feet, Pirate Leader and Marlowe.
- The update reconverts the maps and characters (this takes a while once). The multiplayer files grow by about 2 GB,
  and maps use more video memory; please report any map that stutters or fails to load.

## Uncharted 2 multiplayer

- **Parties could not start a match** when the two PCs had different imports: the host got the "different import"
  message again and again, because the party list was read wrong and both PCs kept resending it. Fixed; the message
  now shows once per player (notice fix by Tha_14).
- **Same game data on every PC:** the import now takes the Uncharted 2 game data from the server download, else the
  Game of the Year data, and only then other releases (for DLC files the GOTY lacks), never by folder name order.
  **Both players of a party should update and import again.**
- Menu selection no longer jumps back to the first item when a list refreshes (by Tha_14).

Still being worked on: freezes in custom games, matchmaking and Fort co-op (issue 55), lag and teleporting players
(issue 56). Please attach your `boot.log` and any `hang-*.txt` / `u3mp-freeze.txt` from the
`analysis\big3-ps4_Shipping` folder to the issue.
