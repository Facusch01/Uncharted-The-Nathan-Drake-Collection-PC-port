**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## New installs of 0.10.117

- **The package was missing a DLL (zlib).** On a new install of 0.10.117 the Uncharted 3 import stopped at
  `eula-pages` ("ffmpeg failed") and the games could not start. Installs updated from an older version still had the
  file and were not affected. If you installed 0.10.117 new, update, then run **RE-IMPORT / UPDATE** once.

## Uncharted 3 import

- **The import works with the server's current game data again.** The server's DATA2 changed: it no longer has the
  Lab map files, and it has a new netgame table (278 netgames). Both made the import stop for new players.
- **Characters get the textures they have on PS3** where the PS4 version had none.

## Uncharted 3 multiplayer

- **Leaderboards:** names, kills, deaths and ranks are shown, and the Friends filter works.
- **No crash at match or round start.**
- **Co-op checkpoint rings and King of the Hill zone rings** have their colour again (they were white).
- **The aiming reticle** keeps the same size at every render size (Low drew it smaller, High and Ultra bigger).

## Launcher

- **Text boxes** (server name, DNS, add friend, ...) take whole words again: before, they lost focus after each letter.
- **Every install keeps its own settings file**, so a second copy of the launcher no longer changes the first one's
  settings.
