**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 co-op with more than one guest (helper v7.239)

- **Enemies on guests move and animate again.** A guest could not decode the enemies' animation state from the
  host, so they flew around, sat in a meditating pose or T-posed. The host no longer sends the part that broke
  it, and a guest skips that part instead of dropping the whole state, so guests with an older host benefit too.
- **The game no longer stalls when one network event goes missing.** Events from another player arrive in order;
  when one never arrived, every later one waited for it (no enemies for guests, grenades that never exploded, a
  box that never finished, a cutscene that left the guests behind, very slow checkpoints). The game now gives up
  on a missing event after about one second and goes on, and drops second copies of events it already has. The
  cause of the missing events is still being looked into.

Still being worked on: the missing events above, map lighting on Facility and a few other maps, freezes in custom
games, matchmaking and Fort co-op (issue 55), lag and teleporting players (issue 56). Please attach your
`boot.log` and any `hang-*.txt` / `u3mp-freeze.txt` from the `analysis\big3-ps4_Shipping` folder to the issue.
