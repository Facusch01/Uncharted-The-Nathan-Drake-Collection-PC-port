**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 multiplayer and co-op

- **Guests see the enemies** in co-op arena, co-op adventure, hunter arena and shade. Until now only the host had them
  (issue 58).
- **Every player's character look reaches everyone.** Guests often saw the other guests in the default look; each
  machine now asks for missing player infos again, as the PS3 game does (issue 57).
- **No more crash in matches with three or four players** ("Allocation failed: 576 bytes"). The network memory pool is
  raised to 16 MiB again: an earlier fix for this never took effect (issue 55).
- **No crash at start** when the game is started again without restarting the launcher (issue 55).

Not fixed yet, still being worked on: the freeze in custom games and matchmaking (issue 55), lag and teleporting
players (issue 56), and guests not throwing grenades (issue 59). If you hit one of them, please attach your `boot.log`
and any `hang-*.txt` from the `analysis\big3-ps4_Shipping` folder to the issue.
