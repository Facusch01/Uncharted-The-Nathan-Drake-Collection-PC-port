**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 multiplayer and co-op

- **Joining a friend's match in progress works with any import** (for example a friend playing Co-op Arena). The two
  players' net game lists can be in a different order, depending on when each one imported. The join was then
  refused with "Unable to join party"; the host's mode is now found by its name.

## Cheats tab: Debug mode (Uncharted 2 and 3)

- **The Dev Menu and Quick Menu open now** (issue 70). Hold the left stick click first, then press the second
  button; the same combo closes the menu:
  - Dev Menu: L3 + Options (Xbox pad: left stick click + Start; keyboard: Left Shift + Esc).
  - Quick Menu, with "Give Player Weapon": L3 + touchpad (Xbox pad: left stick click + Back; keyboard: Left Shift + Tab).
  - Debug fly (L2 + R2) and debug text (L3 + Triangle) are unchanged.
