**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Cheats tab: Debug mode (issue 70)

- **Uncharted 1 has Debug mode and Game speed too**, as Uncharted 2 and 3: the Dev Menu (L3 + Options; Xbox: left
  stick click + Start; keyboard: Left Shift + Esc), the Quick Menu (L3 + touchpad; Xbox: left stick click + Back;
  keyboard: Left Shift + Tab), debug text (L3 + Triangle) and debug fly (L2 + R2 on a second controller, as in
  Uncharted 2).
- **Weapon names in "Give Player Weapon"** for Uncharted 2 and 3. The runtime reads them from your own game's data
  files when the game starts (Uncharted 3: 56 of 66 weapons named, Uncharted 2: 40 of 42; the rest still show a code).
  The list is sorted by name.

## From 0.10.123 and 0.10.124

- Joining a friend's match in progress works with any import, the Dev Menu and Quick Menu open from a PC controller,
  controller support in the launcher window, a portable launcher with nothing in AppData, updates with File Explorer
  open, names over other players placed above them, and the Fort co-op idols.
