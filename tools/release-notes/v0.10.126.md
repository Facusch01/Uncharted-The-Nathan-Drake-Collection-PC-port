**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 multiplayer

- **Voice chat between PC players** (issue 81), as on PS3: your voice travels with the game's own data. Set it in
  the launcher: Uncharted 3 Multiplayer, Voice chat: Off, Open mic or Push to talk (key T by default), and the volume.
  Mute and Unmute a player in the party list and the in-match player list. Players on PS3, RPCS3 or older versions
  hear nothing and are not disturbed.
- **Splitscreen** (issue 31): the Splitscreen row signs in a second local player with a second controller, or with
  keyboard and mouse while the first player uses a controller (then keyboard and mouse only control player 2).
  Choosing it again signs player 2 out. New, please report how it plays in issue 31.
- **Level badges show prestige again** in the party list and the players list (issue 82); players with all co-op
  stars no longer show "1".
- **Friends' stats show at once** (issue 84), and always for the right player.

## All games

- **No white frame at start** in borderless and fullscreen.
- **Multitasking:** the controller keeps playing while another window has the focus; using the controller frees the
  mouse so it can leave the game; a click in the game (or Alt+Tab back) takes it again. The game no longer reacts to
  typing in other windows.
- **Debug mode (Cheats tab):** Uncharted 1's debug menus now show names too.

Still being worked on: freezes in custom games, matchmaking and Fort co-op (issue 55), lag and teleporting players
(issue 56), the broken enemy poses on guests (issue 58) and guests not throwing grenades (issue 59). Please attach your
`boot.log` and any `hang-*.txt` from the `analysis\big3-ps4_Shipping` folder to the issue.
