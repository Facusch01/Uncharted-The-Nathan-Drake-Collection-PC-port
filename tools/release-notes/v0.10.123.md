**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Launcher

- **Controller support in the launcher window** (issue 54): D-pad or left stick to move, A to click, B to go back,
  LB / RB for the tabs, LT / RT for the games, Start to play. The keyboard works the same way (arrows, Enter, Escape,
  Tab). The full list is in `launcher-qt/README.md`.
- **Debug mode on the Cheats tab, Uncharted 2 and 3** (issue 70): turns on the games' own debug menus and debug fly
  (L3 + Options: Dev Menu, L3 + touchpad: Quick Menu with "Give Player Weapon", L3 + Triangle: debug text, L2 + R2:
  debug fly). **Game speed**: 0.2x, 0.5x or 1.75x. Not fully tested yet: please report in issue 70 which combos work.
  Keep the game speed on Normal online.
- **Portable:** the launcher no longer writes to AppData (issue 66). Unless you pick a folder, the Uncharted 3 and
  Uncharted 2 multiplayer files go into the launcher's own folder. An import you already have stays where it is.
- **Updates work with File Explorer open** in the launcher's folder (issue 67). This takes effect from the next update
  after this one.

## Uncharted 3 multiplayer and co-op

- **Names over other players sit above them again** (issue 64). They were placed at 1.5 times their position on the
  screen. Please confirm in issue 64, and tell us if the co-op partner's marker still does not show.
- **Fort co-op: the idols spawn** (issue 45). One effect of the Fort map was converted with part of its data cut
  off. The import redoes that one step on update.

Still being worked on: freezes in custom games, matchmaking and Fort co-op (issue 55), lag and teleporting players
(issue 56), the broken enemy poses on guests (issue 58) and guests not throwing grenades (issue 59). Please attach your
`boot.log` and any `hang-*.txt` from the `analysis\big3-ps4_Shipping` folder to the issue.
