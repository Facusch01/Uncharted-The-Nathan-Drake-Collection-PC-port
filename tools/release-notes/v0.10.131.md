**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Imports

- **Uncharted 3:** imports that still failed with "no fallback material" on every map after 0.10.130 now work. Old
  per-level choice files left over from earlier versions were read as "use no material" for every map. They are now
  ignored.
- **Uncharted 3 live data:** with the community server DNS set, the import first checks whether the server's game data
  changed (one small request). When it is the same, nothing is downloaded again and nothing is converted again.
- **Uncharted 2 live data (new):** the Uncharted 2 page has its own DNS box. With it set, the import downloads the
  Uncharted 2 GOTY game data itself, so RPCS3's game-data folder is no longer needed (it still works as before when no
  DNS is set).

## Multiplayer, Uncharted 3 and Uncharted 2

- **Matchmaking starts with fewer players:** 2 players for every mode, 3 for Three Team Deathmatch, 1 for co-op. Games
  still fill up to the full player count. (Not fully tested yet; please report how it goes.)
- **Uncharted 3: crash in custom games after stuck background work fixed.** When the game's background work got stuck,
  the safety net let the game go on with work that had never been done, and the game then crashed. It now only lets
  finished work through. In the rare case it cannot tell, the game stops with a freeze report instead of crashing, and
  `boot.log` now names what caused it.
- **Graphics driver crashes** ("device lost") now always write the driver's fault report to `boot.log`.

Still being worked on: freezes in custom games, matchmaking and Fort co-op (issue 55), lag and teleporting players
(issue 56) and split screen (issue 31). Please attach your `boot.log` and any `hang-*.txt` / `u3mp-freeze.txt` from the
`analysis\big3-ps4_Shipping` folder to the issue.
