**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 multiplayer

- **Party members load the host's map** (issue 92). When a party started a game together, a player whose game data
  was older (for example from RPCS3) could load another map than the host (London instead of Airstrip) or crash at the
  start ("Failed to even find a default spawner"). The host's map is now always found by its name.
- **The import uses the server's current game data** when a community server DNS is set, at every import and update,
  so every PC gets the same map and mode list. This update re-runs two quick import steps for everyone (recipe 1.28.0).
- **Imports with old game data no longer fail halfway**: an unknown game-data version is caught at the start, and with
  a DNS the current one is downloaded.
- **Power weapons on Airstrip:** still being looked into. This version writes each step of a weapon pickup into
  `boot.log`; please try picking up power weapons on Airstrip and Syria and send both players' `boot.log`.

Still being worked on: freezes in custom games, matchmaking and Fort co-op (issue 55), lag and teleporting players
(issue 56) and the broken enemy poses on guests (issue 58). Please attach your `boot.log` and any `hang-*.txt` from the
`analysis\big3-ps4_Shipping` folder to the issue.
