**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 co-op with more than one guest

- **Network events no longer go missing.** One kind of game event was sent in a longer form than the other player's
  game reads, which made it drop the events that came after it in the same packet. Guests then missed enemies, box
  progress, checkpoints and cutscenes, and each player could end up at a different stage. The event is now sent in
  the form the game reads. All players should update.
- From 0.10.137 / 0.10.138 (helper v7.240): enemies on guests move and animate again, and a missing event no longer
  stalls the game.

Still being worked on: guests who sometimes cannot throw grenades, map lighting on Facility and a few other maps,
freezes in custom games, matchmaking and Fort co-op (issue 55), lag and teleporting players (issue 56). Please attach
your `boot.log` and any `hang-*.txt` / `u3mp-freeze.txt` from the `analysis\big3-ps4_Shipping` folder to the issue.
